## [0.2.0] - 2026-11-27

### Added

* Formal project documentation structure.
* Standardized README.md.
* Design.md.
* Logging.md.
* Sessions.md.
* CHANGELOG.md.

### Changed

* Established PythonTools as the shared foundation library for the Linktech Engineering Tools Suite.
* Defined project-wide architectural principles and responsibility boundaries.
* Standardized documentation formatting across project documents.
* Adopted numbered table-of-contents format consistent with other Linktech Engineering projects.

### Documented

* Deterministic design philosophy.
* Stable module architecture.
* Logger injection model.
* NullLogger behavior.
* Session architecture.
* Local execution model.
* Elevated execution model.
* SSHSession architecture.
* Logging responsibility boundaries.
* Session responsibility boundaries.
* PythonTools ecosystem relationships.

### Notes

Version 0.2.0 establishes the initial formal documentation baseline for PythonTools.

PythonTools already serves as the shared utility and execution library for multiple Linktech Engineering projects including RunUpdates, NMS_Tools, TimerDeck, VSCode-Updater, BotScanner, and future applications.

Documentation and architectural guidance introduced in this release are intended to support future growth while preserving deterministic and reusable behavior.
