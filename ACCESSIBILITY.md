# Accessibility

## Overview

PythonTools aims to support the development of accessible applications and tools.

## Goals

* Prefer structured output over free-form text.
* Support machine-readable data formats.
* Avoid requiring color-only interpretation.
* Support screen-reader friendly output where practical.
* Maintain keyboard-accessible workflows for GUI utilities.

## Limitations

PythonTools is a library and does not directly control the accessibility of consuming applications.

Accessibility responsibilities remain with the application implementing PythonTools functionality.

## Reporting Accessibility Issues

Accessibility concerns may be reported through the issue tracker using the Documentation or Bug Report templates.
